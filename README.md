# 胶片核对台（分镜核对 + 离线修复调度）

纯前端本地应用，无需联网、无需构建，直接打开 `index.html` 即可使用，也可在本目录启动静态服务访问。
顶部两个页签分别面向不同工作：

## 1. 胶片分镜条核对台

整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒、导出清单。

## 2. 离线修复调度台（放映员 / 修复师 / 资料管理员）

- **损伤登记**：每卷片段可勾选多项损伤（清洁、划痕打磨、齿孔修补、补色、重接、放映复检、归档），
  自动汇总工时、派生负责岗位与所需设备；可设优先级、备注，以及跨任务的前置依赖（支持跨卷）。
- **自动排程**：按依赖拓扑、优先级、早晚班工时容量、人员岗位与设备占用求最早可行工作日；
  同一人员、同一设备绝不重叠。人员与设备均可增删。
- **手动改派**：甘特图按人员泳道（附设备占用行）展示，拖动色块改派即"钉住"该任务，
  松手立即标出人员重叠、设备重叠、依赖倒置、岗位不符、缺资源等冲突，并脉冲红框提示。
- **保存门禁**：存在任何冲突（含依赖成环、任务未能排程）时保存按钮禁用，冲突版本**不写入** localStorage，
  刷新即回到上次干净版本。
- **总工期与风险**：任何改动后自动重算预计完工天数与风险指数（损伤基础风险 + 硬冲突×25 +
  其他冲突×8 + 工期×2），并列出风险构成。
- **批量事务**：多选任务批量改优先级或损伤（追加 / 替换），先弹窗预览工期、风险、冲突数量及逐任务改动，
  确认后作为一次事务提交；预检或提交中任一步失败全部回退、零写入。
- **撤销 / 刷新保留**：支持撤销上一次批量提交（撤销栈持久化）；排程、资源、开工日期、撤销栈刷新后均保留。
- **班表导出**：一键导出带 BOM 的 UTF-8 CSV（Excel 中文不乱码），跨工作日任务按天展开，
  未排程 / 冲突任务单列警示段。

数据保存在浏览器 localStorage（键：`zfl17-film-strip-desk`、`zfl17-film-repair-desk-v1`）。

## 端到端验证（真实 Chromium）

```bash
cd .e2e
npm i
npx playwright install chromium
# 在仓库根目录启动静态服务：python3 -m http.server 8717
npx playwright test
```

`.e2e/repair.spec.js` 共 14 个串行用例，覆盖：原核对台回归、多卷登记、依赖成环门禁、
人员/设备拖拽冲突、全自动重排、批量预览/失败回退/成功提交/撤销、追加损伤、刷新保留、
干净与冲突两版 CSV 导出、无空壳入口校验；全程断言页面无 JS 报错。
